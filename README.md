## Featured Projects

<details>
<summary><strong>Agentic AI Productivity Assistant</strong></summary>

Built an Agentic AI operating system using LangGraph and a multi-server MCP-style architecture to autonomously orchestrate complex workflows. The system uses hierarchical task routing to avoid context saturation and dynamically delegates work to specialized tool nodes.

It also integrates a dual-layer memory stack with Episodic RAG and a KuzuDB knowledge graph for persistent state retention. The system is deployed in a secure Docker sandbox and includes a low-latency voice interface powered by Faster-Whisper and Piper.

| Stack | Scale | Performance | Security | Impact | Repository |

<summary><strong>Portfolio Chatbot Using Retrieval-Augmented Generation</strong></summary>

Built a personalized chatbot for my portfolio website using a RAG architecture for information retrieval. I designed a custom document retriever to fetch relevant resume and project data, enabling real-time, context-aware answers.

The response layer is integrated with the Google Gemini API to provide clean, understandable responses and fallback handling for different query patterns.

<summary><strong>Vision Transformer for Skin Disease Classification</strong></summary>

Developed a custom Vision Transformer from scratch to classify skin lesions across 7 diagnostic categories using the HAM10000 dataset. The model was trained with a focus on generalization, accuracy, and efficient learning on limited data.

I also added attention visualization to improve interpretability and support transparency in medical diagnosis workflows.
